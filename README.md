# 📞 Phonebook Application (Java)

A full-stack Phonebook Application built using **Vue.js, Java Spring Boot, MongoDB, Docker, and Nginx**.

## Features

- User registration and login
- Add, view, update, and delete contacts
- Search contacts
- Google-style numbered pagination
- Import and export contacts using CSV
- Contact tags and tag-based filtering
- MongoDB database storage
- Up to 1000 contacts for testing
